CASE STUDY IMAGES
=================

Drop your hero images into this folder using these exact filenames
(the index.html references them by these paths):

  stella-racquet-club.jpg       Stella Artois - Racquet Club Launch
  corona-cero-olympics.jpg      Corona Cero - For Every #GoldenMoment
  corona-island.jpg             Corona - Colombia Island
  tiktok-awards.jpg             TikTok Awards - Larger Than Life
  stella-lets-do-dinner.jpg     Stella Artois - Let's Do Dinner

Recommended image specs:
  - 16:10 aspect ratio (e.g. 1600x1000, 2400x1500)
  - JPG format (smaller file size for hero photos)
  - Full-bleed compositions read best
    (cards crop to fill via CSS object-fit: cover)

The dark gradient placeholders currently in this folder are just
fillers so the design renders before you drop in real photos.
Overwrite them with the same filenames and the cards pick up your
images automatically.

If you want to use different filenames or formats, update the
<img src="..."> paths inside the work__stack section of index.html.
